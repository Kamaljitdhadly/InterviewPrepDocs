# Kubernetes Handwritten

1)  **Kubernetes (K8s)** — Open-source system for automatic deployment, scaling, and management of containerized applications. Replaces failed containers automatically.

2)  **Multi-cloud portability** — Cloud-specific services create vendor lock-in. K8s provides a **standardized configuration format** usable across cloud providers.
