# .NET Core Cookies

## Questions Covered

1. What are the main types of cookies and how do you set them in ASP.NET Core?
2. What are the SameSite cookie values (Strict, Lax, None)?
3. How do third-party cookies work and what are the privacy implications?

## What are the main types of cookies and how do you set them in ASP.NET Core?

Cookies are small data pieces stored on the user's device by the browser while browsing. They enable session tracking, preference persistence, and authentication state across requests.

| Type | Behavior | Example |
|------|----------|---------|
| **Session** | Deleted when browser closes | Shopping cart during a visit |
| **Persistent** | Survives browser close; has expiry | "Remember Me" login |
| **First-party** | Set by the site you're visiting | Language preference |
| **Third-party** | Set by a different domain | Ad network tracking |
| **Secure** | Sent only over HTTPS | Banking session |
| **HttpOnly** | Not accessible via JavaScript (XSS protection) | Session ID |
| **SameSite** | Controls cross-site sending (CSRF protection) | Form submissions |

**ASP.NET Core examples:**

```csharp
// Session cookie (no expiry)
HttpContext.Response.Cookies.Append("SessionCookie", "sessionValue");

// Persistent cookie (30 days)
HttpContext.Response.Cookies.Append("PersistentCookie", "persistentValue",
    new CookieOptions { Expires = DateTimeOffset.UtcNow.AddDays(30) });

// Secure + HttpOnly
HttpContext.Response.Cookies.Append("SecureHttpOnlyCookie", "secureValue",
    new CookieOptions { HttpOnly = true, Secure = true });

// SameSite=Strict
HttpContext.Response.Cookies.Append("SameSiteCookie", "sameSiteValue",
    new CookieOptions { SameSite = SameSiteMode.Strict });
```

## What are the SameSite cookie values (Strict, Lax, None)?

The **SameSite** attribute controls when cookies are sent with cross-site requests, mitigating **Cross-Site Request Forgery (CSRF)** by limiting cookie inclusion in requests initiated by third-party sites.

### SameSite=Strict

Sent **only in first-party context** — not with third-party-initiated requests. Highest CSRF protection; may require re-login after external links.

```csharp
HttpContext.Response.Cookies.Append("StrictCookie", "strictValue",
    new CookieOptions { SameSite = SameSiteMode.Strict });
```

**Use:** banking, highly sensitive actions.

### SameSite=Lax

Sent with same-site requests and **top-level navigation** (clicking links). Not sent with third-party subresources (images, iframes).

```csharp
HttpContext.Response.Cookies.Append("LaxCookie", "laxValue",
    new CookieOptions { SameSite = SameSiteMode.Lax });
```

**Use:** general apps — balance of security and UX (e.g., email link back to site keeps session).

### SameSite=None

Sent with **all** requests including cross-site. **Requires `Secure=true`** (HTTPS only).

```csharp
HttpContext.Response.Cookies.Append("NoneCookie", "noneValue",
    new CookieOptions { SameSite = SameSiteMode.None, Secure = true });
```

**Use:** SSO, payment gateways, cross-site embeds.

| Value | CSRF protection | Cross-site sending |
|-------|-----------------|-------------------|
| Strict | Highest | Never |
| Lax | Moderate | Top-level navigation only |
| None | Lowest | Always (HTTPS required) |

## How do third-party cookies work and what are the privacy implications?

Cookies set by a **domain other than** the one the user is visiting — typically for tracking and advertising.

**How it works:**

1. User visits `news.com` with an embedded ad from `adnetwork.com`
2. `adnetwork.com` sets a cookie on its own domain (third-party cookie)
3. User visits `sports.com` — same ad network reads the cookie and recognizes the user
4. Targeted ads based on cross-site browsing history

**Example — news.com embeds ad script:**

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>News Website</title>
</head>
<body>
  <h1>Welcome to News.com</h1>
  <script src="https://adnetwork.com/ad-script.js"></script>
</body>
</html>
```

**adnetwork.com/ad-script.js:**

```javascript
document.cookie = "adNetworkUserID=12345; path=/; domain=.adnetwork.com; expires=Fri, 31 Dec 9999 23:59:59 GMT";
```

Cookie is set for `adnetwork.com` even though the user is on `news.com`.

**Real-world example:** user browses laptops on `shop.com` (ad network sets cookie) → later visits `news.com` → sees laptop ads because `adnetwork.com` read the same third-party cookie.

**Privacy & browser trends:**

- Enable extensive cross-site tracking, often without explicit consent — regulatory scrutiny (GDPR, etc.)
- **Safari** and **Firefox** block third-party cookies by default
- **Chrome** phasing them out via Privacy Sandbox
- Industry shifting to first-party cookies, server-side tracking, and privacy-preserving APIs
