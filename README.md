# 🎯 Interview Prep Knowledge Base

A comprehensive, example-driven interview preparation knowledge base covering **C#**, **.NET**, **JavaScript**, **Microsoft SQL Server**, and **Angular**.

Every topic is written to help you **confidently answer questions out loud** in real interviews — from fresher to senior level. Each topic includes concept explanations, runnable code examples, interview Q&A (tagged by difficulty), a dedicated **tricky/gotchas** section for the things people commonly get wrong, and a quick-revision cheat sheet.

## 🧭 How to use this repo

- Each topic file follows the same structure:
  1. **Concept Explanation**
  2. **Code Example(s)**
  3. **Interview Q&A** — tagged 🟢 Junior / 🟡 Mid / 🔴 Senior
  4. **⚠️ Tricky / Gotchas** — the confusing bits people get wrong
  5. **📌 Quick Recap** — last-minute cheat sheet
- Read a track in the numbered order, or jump straight to a topic from its track index.
- The night before an interview: skim only the **Quick Recap** and **Tricky / Gotchas** sections.

## 🗓️ Suggested study plan

| Week | Focus |
|------|-------|
| **Week 1** | C# fundamentals + OOP → start .NET basics |
| **Week 2** | Finish .NET (DI, EF Core, ASP.NET pipeline) |
| **Week 3** | JavaScript (closures, `this`, event loop, promises) + Angular core |
| **Week 4** | SQL Server (joins, indexes, window functions, transactions) + revise all Tricky sections |
| **Week 5** | Docker + Kubernetes (containers → orchestration) |
| **Week 6** | Azure Cloud (compute, storage, identity, messaging) |
| **Week 7** | Microservices (communication, data, resilience, observability) |
| **Week 8** | System Design (building blocks + practice the framework on real prompts) |
| **Ongoing** | Data Structures (Big-O + core structures) — revise alongside coding practice |

> Tip: After each topic, close the file and try to explain it out loud from memory. If you can't, re-read the **Quick Recap**.
